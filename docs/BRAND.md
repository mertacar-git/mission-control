# FLW VECTOR

FLW VECTOR is the mission-planning and flight-analysis application from
**FLW Aerospace & Defense**. The former Mission Control project remains at its
existing repository/demo URLs so links, stored missions and recordings continue
to work. Python package names, JSON formats and MCT1 wire identifiers are preserved.

The original SVG mark combines an ascending vector, split wings and a lower
chevron inside a hexagonal frame. It scales from favicon to application header.
It is an application identity; it does not assert certification or hardware readiness.

| Asset | Use |
|---|---|
| `frontend/public/brand/vector-mark.svg` | Full-color application icon and favicon |
| `frontend/public/brand/vector-mark-mono.svg` | Monochrome use on a light background |
| `frontend/public/brand/flw-vector-lockup.svg` | Dark-background product/parent-company signature |

Primary palette: midnight `#101D2A`, mint `#A7EDC3`, flight blue `#86B8ED`,
off-white `#F1F4F8`. Keep the mark's proportions; leave space equal to at least
one wing's width around it. Small instances use the mark alone rather than
compressing the parent-company line. SVGs need no image service or external font.

Code/docs remain English, the operator interface Turkish. Historical evidence
retains the name shown at its original recording date; it is not retouched.
